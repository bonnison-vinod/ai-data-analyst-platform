# AI Data Analyst Platform - Enterprise Edition\n\nA sophisticated, modern data analytics platform with AI-powered insights and beautiful user interface.\n\n## 🚀 Features\n\n- **Modern Classy UI**: Clean, professional interface built with React and Material-UI\n- **AI-Powered Analytics**: Advanced data analysis with OpenAI integration\n- **Real-time Dashboard**: Live metrics and interactive visualizations\n- **File Upload & Analysis**: Support for CSV, Excel, JSON files\n- **Enhanced Reporting**: Comprehensive Excel reports with multiple sheets\n- **Database Integration**: Connect to various databases and APIs\n- **Responsive Design**: Works seamlessly on desktop and mobile\n\n## 🏗️ Architecture\n\n- **Frontend**: React + Material-UI (Port 3000)\n- **Backend**: FastAPI + Python (Port 8000)\n- **Database**: SQLite for development\n- **AI Engine**: OpenAI GPT for data insights\n\n## 📁 Project Structure\n\n```\nai-data-analyst-platform/\n├── Backend/                 # FastAPI backend server\n│   ├── app/\n│   │   ├── main.py         # Main application entry\n│   │   ├── api/            # API endpoints\n│   │   ├── core/           # Core functionality\n│   │   ├── models/         # Data models\n│   │   └── utils/          # Utility functions\n│   ├── requirements.txt    # Python dependencies\n│   └── Dockerfile          # Docker configuration\n├── frontend/               # React frontend application\n│   ├── src/\n│   │   ├── App.jsx         # Main app component\n│   │   ├── components/     # React components\n│   │   └── index.css       # Global styles\n│   ├── package.json        # Node.js dependencies\n│   └── public/             # Static assets\n├── start_platform.bat      # Quick start script\n└── README.md              # This file\n```\n\n## 🚀 Quick Start\n\n### Method 1: Use the Startup Script (Recommended)\n\n1. Double-click `start_platform.bat`\n2. Wait for both backend and frontend to start\n3. Open your browser to `http://localhost:3000`\n\n### Method 2: Manual Start\n\n#### Start Backend\n```bash\ncd Backend\npython -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000\n```\n\n#### Start Frontend\n```bash\ncd frontend\nnpm start\n```\n\n## 🌐 Access Points\n\n- **Frontend Dashboard**: http://localhost:3000\n- **Backend API**: http://localhost:8000\n- **API Documentation**: http://localhost:8000/docs\n- **Interactive API**: http://localhost:8000/redoc\n\n## 📊 Key Endpoints\n\n- `POST /api/upload/` - Upload and analyze data files\n- `POST /api/generate-enhanced-report/` - Generate comprehensive reports\n- `GET /api/dashboard/kpis` - Get dashboard metrics\n- `GET /api/dashboard/health` - System health status\n- `POST /api/magic-question/` - AI-powered data questions\n\n## 💫 User Interface\n\n### Login Screen\n- Clean, modern design with gradient backgrounds\n- Glass morphism effects\n- Responsive layout\n\n### Dashboard\n- Real-time KPI cards with trends\n- Quick action buttons for common tasks\n- Recent analyses overview\n- System status monitoring\n\n### Features\n- Drag & drop file upload\n- Interactive data visualization\n- Comprehensive reporting\n- Mobile-responsive design\n\n## 🛠️ Configuration\n\n### Environment Variables\nCreate a `.env` file in the Backend directory:\n```\nOPENAI_API_KEY=your_openai_api_key_here\nDATABASE_URL=sqlite:///./test.db\n```\n\n### Dependencies\n\n#### Backend\n- FastAPI\n- uvicorn\n- pandas\n- numpy\n- openai\n- python-multipart\n\n#### Frontend\n- React 18\n- Material-UI v5\n- axios\n- chart.js\n- react-router-dom\n\n## 📱 Mobile Support\n\nThe platform is fully responsive and works great on:\n- Desktop computers\n- Tablets\n- Mobile phones\n\n## 🎨 Design System\n\n### Color Palette\n- **Primary**: Deep Navy Blue (#1a365d)\n- **Secondary**: Elegant Gold (#d69e2e)\n- **Background**: Light Gray (#f7fafc)\n- **Text**: Dark Gray (#2d3748)\n\n### Typography\n- **Font Family**: Inter (modern, clean)\n- **Weight Range**: 300-700\n- **Responsive scaling**\n\n## 🔧 Development\n\n### Adding New Features\n1.
